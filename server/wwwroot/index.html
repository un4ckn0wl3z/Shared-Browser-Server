SHARED VAULT

Cookie and session profiles

Sites the primary browser shares (see Share cookies from the primary browser in Browser settings) are added automatically. Sign-outs and cookie expiry on the primary browser are synchronized too. A site can have several accounts (profiles with the same domain and different names); each browser switches between them from its account button, and a new browser uses the first one.

Deleting a profile removes its cookies from every browser except the primary one, which keeps its own cookies. With automatic sharing on, the primary browser shares a domain again the next time its cookies there change. The vault is backed up before every bulk delete.
